# Starship

A resource / exploration / crafting / scheduling game that starts with 1900-era technology and builds toward a starship and travel to other star systems.

Built with TypeScript and Phaser 4, using data-driven design: every resource, technology, building, worker, piece of equipment and recipe is defined in JSON under `/data`.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the design, [PROGRESS.md](PROGRESS.md) for where things stand, and [docs/open-questions.md](docs/open-questions.md) for unresolved questions.
